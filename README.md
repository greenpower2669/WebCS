# WebCS

Reprise du prototype WebCS dans un monorepo.

## Web POC

Le dossier `web/` contient une version autonome du cœur du prototype : aperçu vidéo local, viseur central, analyse de cinq petits points au centre, vote de couleur, score local, collecte optionnelle de caractéristiques et export CSV. Aucune image n'est enregistrée.

Le site historique de référence reste `https://tek4all.online/webcounterstrike/` tant qu'il est accessible. La partie serveur PHP/SQL d'origine devra être reconstruite séparément si les fichiers source ne sont plus disponibles.

## Android

Le squelette `android/poc-camera/` est amorcé pour la prochaine étape native CameraX.
